# 🦆 达克聊产品

> 不聊概念，只聊真相。一个产品人的 AI 时代观察。

## 关于

我是达克。这个播客聊三件事：AI 到底能干什么、不能干什么、以及大多数人搞错了什么。

不贩卖焦虑，不吹技术神话。每一期只讲一个问题，每一个观点都配一个具体的人和故事。
